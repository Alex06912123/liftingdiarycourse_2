Create a new documentation file in the docs/ directory to highlight coding standards for a specific layer of this app.

The arguments will be in the format: "<filename> <description of standards>"
- The first word is the filename (create docs/<filename>.md)
- The rest describes what coding standards to document

$ARGUMENTS

Before writing, read the existing docs/ files to understand the format and style used. Then create the new doc following the same structure and conventions.
